# Поиск по документам: интерфейс

Фронтенд внутренней ИИ-системы поиска по документам (строительство железных дорог и инфраструктуры).
Данные макетные: ответы подбираются по ключевым словам, бэкенда нет.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (маршруты вида /#/q/...)
npm run build      # проверка типов + сборка в dist/
```

## Стек

React 18, TypeScript, Vite, React Router. Стили: обычный CSS с токенами (`src/styles`), шрифт Jost.

## Структура

```
src/
  App.tsx                  маршруты, доступ к разделам администратора
  context/AppContext.tsx   роль, история запросов, свёрнутая панель (localStorage)
  data/                    макетные данные и правила: источники, сценарии, фильтры, документы, журнал
  components/              Sidebar, SearchField (луч + печатающиеся подсказки), FilterBar, FilterRow, Cite, Icon
  features/search/         виды ответа (AnswerViews) и панель источников (SourcesPanel)
  pages/                   HomePage (первый вход), AnswerPage, DocumentsPage, JournalPage
  styles/                  tokens.css (токены), base.css, layout.css, search.css, admin.css
```

## Что реализовано

- Первый вход: история пуста, на экране короткое объяснение; каждый запрос добавляется в «Мои запросы».
- Пять типов ответа: список документов, сводка со сносками, факт из таблицы, статус объекта, расхождение.
  Состояния «не найдено» и «источник удалён».
- Справа список источников (2–10) в виде аккордеона; номер сноски совпадает с номером карточки.
- Область поиска: фильтры Объект / Тип / Период и сохранённые области (вместо списка групп).
- Роли: «Пользователь» не видит разделы «Документы» и «Журнал запросов» (маршруты закрыты). Переключатель роли в левой панели.
- Свечение только у основных кнопок; поле запроса с полупрозрачным лучом по контуру.
  Все анимации отключаются при `prefers-reduced-motion`.

## Где подключать бэкенд

- `classifyQuery` в `src/data/scenarios.ts` — заглушка поиска. Заменить на запрос к API.
- `ask` в `AppContext` — сохранение запроса; сейчас в localStorage.
- Данные документов и журнала — `src/data/documents.ts`, `src/data/journal.ts`.

## Открытые вопросы

- Кто проставляет «Объект», «Тип», «Период» (админ при загрузке или система) и есть ли справочник объектов.
- Основной технический риск: распознавание таблиц и сканов.
